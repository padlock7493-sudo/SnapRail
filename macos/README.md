# SnapRail · 随手挂 — macOS 1.0.0 开发者指南

macOS 当前以源码形式发布，面向开发者本机构建；Releases 不提供面向普通 Mac 用户的安装包。

Swift / AppKit / SwiftUI 原生实现，按 Windows 1.0 的界面、功能与交互移植。最低 macOS 13；macOS 14+ 使用 ScreenCaptureKit。构建脚本生成当前 Mac 架构的 `.app`，无需 .NET 或第三方依赖。Windows WPF 版保留在 `src/`。

## 构建与运行

需要 Apple Command Line Tools（`xcode-select --install`），无需完整 Xcode。

```sh
./scripts/build-macos.sh
open release/macos/SnapRail.app
```

可将应用复制到 `~/Applications`。这是菜单栏应用，不显示 Dock 图标；关闭窗口不等于退出，退出使用菜单栏中的“随手挂”。当前为本机临时签名版本，尚无 Developer ID 签名与公证。

## 使用

1. **Control+Option+A**：截图。首次需在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”（旧版系统为“屏幕录制”）中允许 SnapRail；若系统要求，请退出后重开。
2. 拖动框选、单击选窗口，或 **Control+A / Command+A** 选择鼠标所在屏幕。可拖动边缘或手柄调整选区，方向键微调。
3. 双排工具栏提供选区、对象、矩形、椭圆、箭头、画笔、中文多行文字、像素马赛克、六色调色板、线宽、字号、撤销/重做、删除、OCR、长截图及另存为。
4. “对象”工具可移动、改色、调整线宽、字号或删除已有标注，双击文字可重新编辑。文字输入 Enter 换行，Command+Enter 完成。
5. **Enter / 完成并挂上**：保存 PNG、可编辑原图和标注，复制完整图片并挂到屏幕顶部。**Esc / 右键**取消当前操作。
6. **Control+Option+T**：展开/收起挂图；设置可开启顶部悬停及离开后自动收起。

截图、OCR 和资料处理均在本机完成，不上传图片。

## 与 Windows 版对应的界面

- **晾衣绳**：整屏双色弧线、端点、粉绿夹子、欢迎字卡；新截图/展开轻摆，系统“减少动态效果”设置会关闭动画。
- **挂图**：单击复制、双击预览、拖动排序、Esc 取消排序、向其他应用拖出 PNG。点击夹子变为桌面贴图；收藏最多 3 张，金色星章夹和收藏徽章，收藏靠左；超出容量用“＋”进入历史。
- **置顶贴图**：复制/编辑/识字/挂回，拖动上沿移动，滚轮缩放，Control+滚轮调整透明度；位置、尺寸和透明度持久化，重新启动恢复。关闭或 Esc 挂回。
- **历史**：原版列表布局、缩略图、日期时间和文件名；全部/收藏/挂图/待挂筛选，搜索，每页 24 张。Ctrl 或 Cmd 多选，Shift 连续选择；批量挂图、贴图、收藏、隐藏、移至系统废纸篓，撤销上次删除同时恢复原图与标注。删除前确认，包含收藏数量。
- **预览**：深色背景，适应窗口/实际大小/缩放、复制/另存为/编辑副本，滚动查看长图，Control+滚轮缩放，Esc 关闭。
- **设置**：原版两栏布局；录制两组快捷键、保存目录迁移及 SHA-256 校验、目标显示器、登录启动、悬停、动画、尺寸、顶部距离和展开/收起延迟，保存并重启。新快捷键冲突时保留旧绑定。
- **OCR**：Apple Vision 中英文本机识别，文字可修改并复制；识别结果需校对。
- **滚动长截图**：自动向下滚动、手动追加、停止、预览并编辑。重叠匹配不可靠、画面不变或达到 80 帧/30000 像素高/5000 万像素时停止。自动滚动需要用户授予辅助功能权限；手动追加不需要。

## macOS 的必要差异

窗口标题栏、文件选择器、权限提示、系统废纸篓、显示器标识和登录项目使用 Mac 系统机制。Windows 使用的系统字体不随仓库分发，中文字体使用 Mac 本机字体，字形和系统窗口边框不会逐像素相同。

默认截图和挂图快捷键与 Windows 一致；编辑支持 Ctrl 以及 Mac 的 Cmd。macOS 的 Command+Q / Command+W 保留给系统；自定义快捷键在保存前检查冲突。

Windows 便携目录和旧版 JSON 结构不会直接覆盖 Mac 资料库。可通过“导入图片”导入 PNG；Windows 标注 JSON 目前不支持跨平台导入。Mac 自身创建的标注资料可持续编辑。

## 本地资料

默认保存于应用同级 SnapRail-data/，可在设置迁移到空目录；迁移保留原数据并逐文件校验。不可写或系统隔离路径回退到用户 Application Support/SnapRail；已有配置路径保持不变。

```text
SnapRail.app 同级的 SnapRail-data/
├── images/                 完整 PNG
├── documents/              原图 PNG 和可编辑标注 JSON
├── library.json            历史、收藏、顺序与贴图位置
├── recovery.json           最近一次删除的系统废纸篓映射
├── welcome-seeded          欢迎图一次性标记
└── app.lock                单实例锁
```

“从绳子取下”只隐藏，不删除文件。清空系统废纸篓后不能保证恢复。“编辑副本”生成新挂图，保留旧图。

## 验证与隔离测试

```sh
./scripts/test-macos.sh
# 独立资料库启动，不修改日常资料
open -n release/macos/SnapRail.app --args --profile /tmp/SnapRail-review
# 用本地生成的无个人资料演示底图检查框选与标注；不读取屏幕
open -n release/macos/SnapRail.app --args --profile /tmp/SnapRail-review --demo-capture
```

自动检查：像素尺寸、裁剪、对象样式和删除、撤销重做、像素马赛克、可编辑副本、资料库重载、收藏上限、贴图状态、排序、删除恢复持久化、目录迁移、欢迎卡生命周期、真实 Vision OCR，以及长图拼接的逐字节像素结果。

已在本机通过真实 ScreenCaptureKit 截图、Chrome 本地页面自动滚动（9 帧、2150×3614 像素）和中英 OCR。登录启动及多屏/混合缩放仍需相应硬件和会话验证。本机已在系统设置核对并开启独立 SnapRail 的两项权限，正常启动复测真实采集与自动滚动成功（运行中记录到 26 帧、2150×10300 像素）。
