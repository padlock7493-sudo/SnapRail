# SnapRail 1.0.0 正式版发布验证

日期：2026-11-04。平台：Windows 11 x64 10.0.26200；.NET SDK 10.0.403，自包含 Windows x64 发布。EXE 文件版本 1.0.0.0，产品版本 1.0.0。

## 本轮验证

- 31 项行为检查通过，覆盖欢迎图只初始化一次、便携路径、标注与像素合成、旧版本保留、历史/收藏/回收恢复、损坏状态保护、迁移及剪贴板。
- 8 项截图编辑实机检查通过：物理像素选区与一像素移动、六种标注、中文多行、撤销重做、原图与标注保存、再次编辑和旧版本保留、全屏与取消。
- 双屏实机通过：3072×1920 / 150% 主屏，2160×1440 / 125% 副屏，副屏为负坐标；两屏像素一致、跨屏 400×300 像素一致、悬浮移动挂图栏、混合 DPI 贴图拖动、重启后副屏几何恢复。
- 收藏最多 3 张、自动靠左、第 4 张拒绝且菜单不误勾；拖动抬起/背景缩小、排序和 Esc 取消；设置控件可见、滑轨点击生效、历史分段筛选通过。
- OCR 与滚动拼接等补充实机结果、最终解压启动和归档审计，以发布目录 verification.json 为准。

双屏脚本在取基线前补充隐藏挂图，避免把屏幕上的挂图栏误当成目标内容；生产截图实现未改变。
