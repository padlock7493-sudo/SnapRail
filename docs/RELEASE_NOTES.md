# SnapRail · 随手挂 1.0.0 正式版

**Windows x64 免安装截图工具 · 2026-11-04 · MIT 开源**

截一张，随手挂一下！截图、标注、自动保存与复制，把常用图片挂到屏幕顶部。

## 下载

- SnapRail-v1.0.0-Portable-win-x64.zip：Windows 用户下载，完整解压后运行 SnapRail.exe，无需安装 .NET。
- SnapRail-v1.0.0-source.zip：完整源码，包含图文 README、开发文档与测试代码。
- SnapRail-v1.0.0-Guide.zip：图文说明离线包，解压后阅读 README.md。
- SHA256SUMS.txt：下载完整性校验。

## 功能

- 区域、窗口、全屏、跨屏截图，自动保存、复制并挂图。
- 六种标注、对象编辑、撤销重做、编辑副本保留旧版本。
- 卡通弯绳、沿绳拖动排序、抬起让位、轻摆动画与“＋”历史入口。
- 最多 3 张收藏，自动靠左、金色夹子标识和超限提醒。
- 单击复制、双击预览、拖出 PNG、置顶贴图和重启恢复。
- 历史搜索、分段筛选、多选、系统回收站删除与撤销。
- 本机 OCR、自动/手动滚动长截图。
- 自定义快捷键、多屏混合 DPI、两栏设置、挂图尺寸与延迟调节。
- 03E 雾蓝正式图标，首次空资料库生成 10 张彩色欢迎图。

## 使用与数据

Ctrl+Alt+A 截图，Enter 完成，Ctrl+Alt+T 展开/收起。保留 EXE 旁的 SnapRail.portable；截图、历史和配置跟随程序文件夹。

发行包不带开发者截图、历史或配置。升级前退出并备份自己的资料，替换 EXE，保留个人 images、documents 和配置。

## 兼容范围

主要在 Windows 11 x64 实测。Windows 10、HDR、独占全屏、热插拔/睡眠唤醒及各类聊天软件仍有未覆盖场景。程序未签名，OCR 和拼接结果需检查。

图文介绍见 README.md，详细操作见使用说明.md，实际验收范围见 verification.json。
