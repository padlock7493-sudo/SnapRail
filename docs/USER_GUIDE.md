# SnapRail · 随手挂 v1.0.0

Windows x64 免安装截图工具。解压整个文件夹后双击 `SnapRail.exe`，无需另装 .NET。

## 启动与数据

保留 EXE 旁的 `SnapRail.portable`。截图在同目录 `images`，原图与标注在 `documents`；`settings.json` 保存设置，`library.json` 保存收藏、贴图和排序，`logs` 为日志。便携模式固定使用程序目录，移动前从托盘退出，再复制整个文件夹。请从可写目录运行。

如果已启用开机启动，移动文件夹后请在设置里重新保存一次，更新启动路径。

首次启动没有截图记录时，会在 `images` 生成“截、一、张、，、随、手、挂、一、下、！”共 10 张彩色欢迎 PNG。欢迎图可在历史查看和删除，删除后不会自动补回；已有截图资料库不会自动插入欢迎图。

## 截图与编辑

- 默认 `Ctrl+Alt+A` 截图：单击选择窗口，或拖动框选；支持跨屏。拖动八个手柄调整选区，方向键微调，Shift 每次 10 像素；`Ctrl+A` 选择鼠标所在屏幕。
- Enter 确认后，自动保存、复制并挂到绳子上。Esc / 右键取消。
- 矩形、椭圆、箭头、画笔、文字、局部马赛克；“对象”工具选择后可移动、改色、改线宽/字号或 Delete 删除。双击已有文字修改。
- `Ctrl+Z` / `Ctrl+Y` 撤销重做，保留最近 100 步。文字编辑中 Enter 换行，`Ctrl+Enter` 完成文字；Esc 放弃当前文字。
- 重新编辑保存为新图，旧版本保留。保存失败时图片留在内存，可重试保存或另存为。

## 挂图与桌面贴图

- 默认 `Ctrl+Alt+T` 展开/收起；也可将鼠标停在屏幕顶部中央。
- 绳子铺满当前屏幕工作区，两侧各留 16 物理像素。图片放不下时，右侧“＋”进入历史，无横向滚动条。
- 单击复制，双击预览。预览支持适应窗口、实际大小、Ctrl+滚轮缩放及长图滚动；Esc 关闭。双击的第一下也会复制。
- 点住图片抬起，邻图缩小下沉；沿绳拖动排序，松手保存，Esc 取消。收藏保持左侧分组。
- 拖出挂图栏向其他应用导出独立 PNG 副本，原图保留。
- 收藏最多 3 张，使用金色星章夹与“收藏”标签。第 4 张会被拒绝并轻晃提示，菜单勾选保持实际状态；历史批量收藏同样受限。
- 点击夹子取下为桌面置顶贴图；拖动上沿移动、滚轮缩放，Ctrl+滚轮调整透明度。关闭或“挂回”返回绳子，重启恢复位置和大小。
- 启用动画后，展开时可见挂图依次轻摆一次，新截图挂上也会摆动，不循环播放。

## 历史与设置

历史支持日期、时间、文件名搜索，及“全部 / 收藏 / 挂图 / 待挂”分段筛选，每页 24 张。Ctrl 多选、Shift 连续选择。可重新挂图、复制、另存为、贴到桌面、收藏、取下、编辑副本、识别文字、删除到回收站、撤销上次删除。

“从绳子取下”只隐藏挂图。删除会将 PNG、原图及标注打包移入系统回收站；撤销恢复最近一组，清空回收站后无法保证恢复。

设置为两栏，无需滚动。可录制快捷键、指定屏幕、调整尺寸/顶部位置/展开与收起延迟、控制动画和开机启动。绿色滑轨为已调节部分。保存并重启生效。快捷键冲突时拒绝新绑定并保留原绑定；启动时占用则提示，可从托盘进入设置。

## OCR 与长截图

“识别文字”使用本机 Windows OCR，可修改结果再复制。没有语言组件时会提示，不自动安装。关闭窗口取消，最长 60 秒；长边超过 4000 像素会缩小识别，文字和中文标点请自行校对。

长截图：先框选可滚动正文、避开固定栏，再点“长截图”。选择“自动向下滚动”，或手动滚动后“追加当前画面”；相邻画面需要有重叠。停止后“预览并编辑”，确认才保存挂图。未保存的长图关闭会要求确认。画面不变、对齐不可靠或达到 80 帧 / 30000 像素高 / 5000 万像素时停止。动画、重复内容和固定悬浮栏可能无法拼接，请检查结果。

## 已知范围

主要在 Windows 11 x64、150% 主屏和 125% 副屏上验证。Windows 10、真实睡眠唤醒/热插拔、HDR、受保护内容和不同聊天软件仍需进一步兼容性验证。程序尚未代码签名。截图、OCR 均在本机处理，无云同步。
